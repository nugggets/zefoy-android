# Zefoy App (Android UI + Backend Adapter)

Этот архив содержит:
- Android приложение (Kotlin) в папке android/
- Backend (FastAPI) и пример worker в папке backend/
- GitHub Actions workflow для сборки APK (debug и опционально signed release)

Инструкции в README внутри android/ и backend/ после загрузки в репозиторий.
